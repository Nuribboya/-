# 리셀 레이더 (ResellRadar)

한정판·콜라보 발매 일정을 모아서 **응모할 가치가 있는 것만** 골라주고, 텔레그램으로
알려주는 윈도우 프로그램입니다. 응모·결제는 직접 합니다 (자동 응모/매크로 기능 없음 —
대부분의 발매처 약관 위반이고 계정 정지 사유입니다).

## 받기

GitHub 저장소의 **Releases → `resell-radar-latest`** 에서 `ResellRadar.exe` 를 받거나,
**Actions → Build ResellRadar.exe → 최신 실행 → Artifacts** 에서 받습니다.

exe 는 아무 폴더에나 두면 되고, 설정과 데이터는 **exe 와 같은 폴더**에 생깁니다.
(처음 실행 시 윈도우 SmartScreen 경고가 뜨면 "추가 정보 → 실행")

## 사용법

더블클릭하면 메뉴가 뜹니다.

1. **처음 실행** — 설정 화면
   - 텔레그램 알림: @BotFather 에서 봇을 만들고 토큰을 붙여넣은 뒤, 그 봇에게 아무
     메시지나 보내면 자동으로 연결됩니다. (알림 없이 쓰려면 엔터)
   - 최소 순수익(기본 30,000원), 최소 수익률(기본 20%)
2. **지금 확인하기** — 수집 → 판정 → 알림을 한 번 실행하고, 결과 화면(`report.html`)을
   브라우저로 엽니다. 카드마다 판정·등급·예상 순수익·마감까지 남은 시간·판정 근거가 나오고,
   추천/애매/패스 탭과 마감 임박순/수익순 정렬이 있습니다. 엑셀용 `latest_report.csv` 도 함께 저장됩니다.
   자동 실행 중에도 `report.html` 은 매번 갱신되므로 메뉴 **5) 마지막 결과 화면 열기**로 언제든 볼 수 있습니다.
3. **3시간마다 자동 실행 등록** — 윈도우 작업 스케줄러에 등록. 컴퓨터가 켜져 있을 때만 돕니다.

명령어로도 실행할 수 있습니다: `ResellRadar.exe run`, `setup`, `schedule --hours 3`, `unschedule`

## 일정 수집처

| 수집처 | 방식 |
| --- | --- |
| 나이키 SNKRS (KR) | 자동 — SNKRS 웹페이지가 쓰는 공개 상품 피드 |
| 그 외 (무신사, 크림 드로우, 편집숍, 해외 등) | `releases.csv` 에 직접 입력 |

`releases.csv` 열: 상품명, 발매처, 응모시작, 응모마감, 발매일, 정가, 방식(응모/선착순),
발매처수, 재발매(Y/N), 예상시세, 링크. 날짜는 `2026-11-01 10:00` 형식.
**예상시세에 크림 실제 시세를 적으면** 등급으로 추정한 가격 대신 그 값으로 수익을 계산합니다.

## 판정 방식

1. **협업 상대 등급** (S/A/B/C) — `tiers.json` 에 들어 있고 직접 고칠 수 있습니다.
   협업 상대가 둘 이상이면 가장 높은 등급 + 1.
2. **조정**
   - 인기 실루엣(조던 1, SB 덩크, 코비) +1
   - 같은 협업 상대가 최근 1년 3회 이상 −1 (프로그램이 본 기록 기준)
   - 재발매 −1, 발매처 5곳 이상 −1, 선착순 −1
3. **수익 기준**
   - 예상 순수익 = 예상시세 × (1 − 판매수수료 6%) − 배송비 4,000원 − 정가
   - 예상시세가 없으면 등급별 배수(S 1.8 / A 1.4 / B 1.15 / C 1.0)로 추정
   - 최소 순수익·수익률 미달이면 등급과 상관없이 **패스**
   - 통과하면 S/A → **추천**, B → **애매**

판매수수료·배송비는 `settings.json` 에서 바꿀 수 있습니다. 플랫폼 수수료는 바뀌므로
쓰는 곳의 현재 요율로 맞추세요.

## 알림

- **추천**이 처음 잡히면 1회
- 응모 마감 3시간 전 1회 (`remind_hours_before_end`)
- 애매도 받으려면 `settings.json` 의 `notify_maybe` 를 `true` 로

## 한계

- 협업 등급표는 2024~2026년 리셀 자료 + 판단으로 만든 **출발점**입니다. 실제 시세 기록이
  `resell_radar.db` 에 쌓이므로, 이후 버전에서 이 기록으로 등급을 보정할 예정입니다.
- 크림 시세는 자동으로 가져오지 않습니다 (공개 API가 없고 약관상 자동 수집이 제한됨).
- 나이키 피드 형식이 바뀌면 수집이 실패할 수 있습니다. 실패해도 프로그램은 멈추지 않고
  `[경고]` 로 알려주며, `releases.csv` 입력분은 그대로 판정합니다.

## 개발

```bash
python -m resell_radar run          # 데이터는 ./resell_radar_data/
pytest tests/test_resell_radar.py
```

외부 패키지 없이 파이썬 표준 라이브러리만 씁니다. exe 는
`.github/workflows/resell-radar-exe.yml` 이 윈도우 러너에서 PyInstaller 로 만듭니다.
