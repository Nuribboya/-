# minecraft-ai

마인크래프트(자바 에디션)를 **스스로 플레이하고 배우는 AI 봇**. 두뇌는 Claude API 또는 로컬 Ollama 모델로 바꿔 끼울 수 있고, 방송용 오버레이(생각 자막·스탯·새 스킬 알림)가 들어 있습니다.

## 동작 방식
1. **관찰**: 위치/체력/인벤토리/주변 블록·몹을 텍스트로 요약
2. **판단 (fast 모델)**: JSON으로 다음 행동 선택 — 기존 스킬 실행 / 새 스킬 작성 / 대기
3. **스킬 작성 (smart 모델)**: 필요한 스킬을 JS 코드로 작성 → 실행 → 에러를 피드백받아 최대 3회 수정 → 성공하면 `data/skills/`에 저장
4. **자동 커리큘럼**: 나무 → 작업대 → 나무곡괭이 → 돌곡괭이 → 화로 → 철 → 철곡괭이 → 다이아
5. **교훈 기록**: 죽음/스킬 작성 실패 원인을 `data/memory.json`에 저장해 프롬프트에 포함

모델 가중치는 바뀌지 않습니다. 학습 = 스킬 라이브러리 + 교훈 메모.

## 실행
```bash
cd minecraft-ai
npm install
cp .env.example .env   # 값 채우기 (ANTHROPIC_API_KEY 등)
set -a; source .env; set +a
npm start
```
- 마인크래프트에서 싱글플레이 월드를 열고 "LAN으로 열기" 후 표시되는 포트를 `MC_PORT`에 넣거나, 전용 서버(`online-mode=false` 권장)를 사용하세요.
- 방송: OBS → 소스 추가 → 브라우저 → `http://localhost:3000` (배경 투명).

## 일지(저널)
`data/journal.jsonl`에 시간순으로 기록합니다: 죽음(원인·위치·낮/밤·직전 행동), 큰 피해(-3 이상, 추정 원인), 스킬 성공/실패(에러 포함), 새 스킬, 목표 달성. 최근 기록과 죽음 통계는 매 판단 프롬프트에 들어가서, 같은 실수를 피하는 데 쓰입니다.
```bash
npm run report   # 죽음/마일스톤/새 스킬 요약 출력
```

## 반성(self-improvement) 루프
`REFLECT_EVERY`(기본 25) 판단마다 쌓인 실패를 모아 분석합니다.
1. 최근 3번 이상 실패한 스킬은 에러 메시지와 현재 코드를 함께 smart 모델에 주고 **고쳐 쓰게** 합니다 (한 번에 최대 2개).
2. 일지와 기존 교훈을 **최대 8개의 짧은 교훈으로 다시 정리**해서 프롬프트에 반영합니다.
결과는 일지의 `reflect_fix`, `reflect` 항목으로 남습니다.

## 플레이어처럼 플레이
- **밤에도 활동**: 밤에도 쉬지 않고 작업합니다. 지표엔 적대 몹이 많아서 밤엔 광질·동굴 같은 지하 작업을 권합니다. 체력이 낮고 몹에 몰렸을 때만 `night_shelter`(땅 3칸 파고 지붕 덮기)로 잠깐 숨습니다. `sleep_in_bed`는 밤을 건너뛰고 싶을 때만 씁니다.
- **침대**: 계획 기능이 "양 3마리 잡기 → 판자 → 작업대 → 침대"를 계산하고, `hunt_animal`로 양을 잡아 양털을 줍습니다. 자면 부활 지점이 침대로 바뀝니다. LAN처럼 여러 명이 있는 월드는 기본 설정상 **모든 플레이어가 자야** 밤이 넘어갑니다 (`/gamerule playersSleepingPercentage`로 조절).
- **죽음 패턴 학습** (`src/deaths.js`): 죽을 때 원인·낮밤·높이·지하 여부·갑옷·무기·직전 행동을 기록하고, 최근 죽음에서 반복 패턴을 찾으면 행동을 직접 바꿉니다. 밤 지상에서 몹에게 2번 → 밤엔 지상을 위험으로 판단, 크리퍼 2번 → 경계 16칸, 몹 3번 → 경계 14칸, 갑옷 없이 2번 → 갑옷·방패 먼저, 용암 1번 → 파 내려갈 때 확인 범위 확대, 낙사 2번 → 2칸 넘게 안 뛰어내림, 굶주림 1번 → 허기 12부터 먹기. 패턴은 교훈과 판단 프롬프트에도 들어가고, `npm run report`에 정리됩니다. 봇이 여러 마리면 서로의 죽음에서 함께 배웁니다.
- **물·용암 안전**: 블록을 파기 전에 그 블록의 위·옆에 물이나 용암이 닿아 있으면 파지 않습니다(바다 밑 굴이 물에 잠기는 걸 방지). 위에 모래·자갈이 있어도 파지 않습니다. 광물이 물 옆에 있으면 건너뛰고 안전한 걸 캡니다. 머리가 7초 넘게(`DROWN_AFTER_MS`) 물속에 있으면 하던 일을 멈추고 위로 헤엄쳐 올라갑니다. (서버가 보내는 숨 수치는 버전에 따라 엉뚱한 값이 와서, 물 밖에선 무시하고 실제로 머리가 물속인지를 봅니다.)
- **끼임 탈출**: 스킬 실행 중 "걷는 중"인데 15초(`STUCK_MS`) 동안 1칸도 못 움직이면 끼었다고 보고 그 스킬을 바로 멈춥니다(블록을 캐는 중은 제외). 다음 턴에 모델 호출 없이 `unstuck`을 실행해, 몸이 낀 블록과 앞을 막는 블록을 부수고(물·용암 옆은 제외) 다른 방향으로 빠져나옵니다.
- **아이템 회수**: 죽으면 위치·원인·들고 있던 아이템을 기억했다가, 부활하자마자 모델에게 묻지 않고 죽은 자리로 가서 떨어진 아이템을 줍습니다(`recover_items`). 아이템이 이미 사라졌을 경우(죽고 4.5분 이상, 용암·월드 밖 낙사)나 빈손이었으면 가지 않고, 한 번 죽을 때 한 번만 시도합니다.
- **횃불**: 지하·굴 안(머리 위가 막혀 있고 어두움)에서 파고 다닐 때 약 8칸마다 자동으로 횃불을 놓습니다. 횃불이 없으면 석탄/숯 + 막대기로 4개씩 만듭니다. 어두운 곳에서 몹이 생기는 걸 줄여요. 끄려면 `TORCHES=false`.
- **광질**: `descend_mine {y}`로 계단식으로 파 내려갑니다(기본 y=-58). 매 칸마다 용암·물·낭떠러지를 확인하고 보이면 멈춥니다. `explore_cave`로 근처 동굴에 들어갑니다. 광석이 없으면 에러 메시지가 그 광석이 많은 높이를 알려줍니다.
- **목표 스스로 정하기**: 정해진 순서는 철 곡괭이까지입니다. 그 뒤로는 봇이 상황(인벤토리, 죽음 기록, 최근 목표)을 보고 다음 목표를 스스로 고릅니다(다이아, 갑옷, 침대, 농장 등). 아이템으로 확인 가능한 목표는 인벤토리에 생기면 달성, `FREE_GOAL_MAX_STEPS`(80)턴이 지나면 포기하고 교훈을 남깁니다.

## 게임 지식 (자동 계획)
프롬프트에 위키를 통째로 넣지 않고, 게임 데이터(minecraft-data)에서 필요할 때 계산합니다.
- 매 판단마다 현재 목표까지의 **단계별 계획**과 **추천 다음 행동**(기본 스킬 호출)을 넣어줍니다. 예: 빈손 → 나무 곡괭이 = 원목 3 → 판자 → 막대기 → 판자 → 작업대 → 설치 → 곡괭이.
- 스킬 코드에서 쓸 수 있는 조회 함수: `api.recipe(item)`, `api.toolFor(block)`, `api.plan(item, count)`.
- 기본 스킬 추가: `mine_block {block, count}`, `smelt_item {item, count, fuel}`.
- 굽기 레시피와 광석 위치처럼 데이터에 없는 것은 `src/knowledge.js`에 직접 적어두었습니다.

## 내 설정은 `.env.local`에
포트 번호, 봇 수 같은 **개인 설정은 `.env.local`** 파일에 적으세요(없으면 만들기). `.env.free`보다 우선하고, git이 건드리지 않아서 `git pull` 때 충돌이 나지 않습니다.
```
MC_PORT=55414

```

## 봇 여러 마리 (집단 학습)
`.env.free`에 `BOT_COUNT=2`(최대 8)를 넣으면 한 프로그램에서 봇 여러 마리가 같은 월드에 접속합니다 (`MC_USER`, `MC_USER_2`, ...).
- **공유**: 스킬 라이브러리, 교훈, 일지(항목마다 어느 봇인지 표시), 모델. 한 봇이 배운 스킬과 다른 봇의 죽음 원인을 모두가 씁니다.
- **각자**: 인벤토리, 진행 상황·목표(`data/bots/<이름>/memory.json`), 발전 과제.
- 로컬 모델 하나를 나눠 쓰므로 봇이 늘수록 각 봇의 생각은 느려집니다(자동 진행 덕분에 2~3마리는 무난). Ollama가 요청을 동시에 처리하게 하려면 환경 변수 `OLLAMA_NUM_PARALLEL=2`(그래픽 메모리 여유가 있을 때).
- `npm run new-world`는 모든 봇의 진행 상황을 함께 초기화합니다.

## 새 월드로 옮길 때
```bash
npm run new-world
```
배운 스킬과 일지는 그대로 두고, 이전 월드의 진행 기록(마일스톤, 현재 목표, 발전 과제 메모, 사망 횟수, 좌표가 들어간 교훈)만 초기화합니다. 실행 전에 두뇌를 자동 저장하니 `npm run brain -- restore <이름>`으로 되돌릴 수 있습니다. 포트 번호(`MC_PORT`)도 새 월드에 맞게 바꾸세요.

## 발전 과제 따라가기
철 곡괭이 다음부터는 **아직 못 한 발전 과제**를 순서대로 목표로 삼습니다(모델 호출 없이 바로 결정). 서버가 접속 때 보내는 발전 과제 진행 데이터로 이미 달성한 것까지 알고, 채팅의 "has made the advancement" 줄은 예비로 씁니다.
- 현재 도구로 가능한 것: Suit Up(철 투구 착용) → Husbandry(먹기) → Monster Hunter(적대 몹 처치) → Not Today, Thank You(방패로 화살 막기) → Sweet Dreams(침대에서 자기) → Diamonds! → Cover Me with Diamonds(다이아 투구 착용)
- 아이템을 만든 뒤 할 일(입기, 먹기, 자기)도 자동 계획에 나옵니다 (`equip_item` 기본 스킬 추가).
- 다 하면 예전처럼 스스로 목표를 고릅니다. 끄려면 `ADVANCEMENT_GOALS=false`.
- 오버레이와 `npm run report`에 달성한 발전 과제가 표시됩니다.

## 속도
- **자동 진행(autopilot)**: 계획대로 잘 되고 있으면 모델에게 묻지 않고 다음 단계를 바로 실행합니다. 직전 행동이 실패했거나, 위험(체력 8 이하, 허기 6 이하, 적대 몹 10칸 이내)하거나, 계획이 없거나, 5턴 연속 자동 진행했으면 모델이 판단합니다. 끄려면 `AUTOPILOT=false`, 연속 횟수는 `AUTOPILOT_MAX_STREAK`.
- 턴 사이 대기 기본값 0.3초(`DECISION_INTERVAL_MS`).
- **`follow_plan {steps}`**: 자동 계획의 다음 단계들을 모델에게 다시 묻지 않고 한 번에 연달아 실행합니다(최대 8단계). 계획이 끝나거나, 단계가 실패하거나, 아무것도 안 바뀌면 멈춥니다. 시간 제한은 일반 스킬의 4배.
- **Ollama**: 모델을 메모리에 계속 올려두고(`OLLAMA_KEEP_ALIVE`, 기본 60m), 답변 길이를 용도별로 제한합니다(판단 450, 목표 250, 반성 600, 코드 1500 토큰).
- 더 빠르게: `.env.free`에서 `SMART_MODEL`을 `FAST_MODEL`과 같은 모델로 두면 모델 교체 시간이 사라집니다.

## 실전 지식 메모 (`src/wiki.js`)
위키를 통째로 넣지 않습니다(작은 모델은 글이 길수록 판단이 나빠지고, 위키 글은 비상업 라이선스). 대신 게임 데이터에 없는 실전 노하우(몹 대처, 광질 안전, 갑옷·철 우선순위, 음식, 농사, 침대, 네더·마법 준비 등 16개 주제)를 직접 짧게 정리했고, 매 판단마다 **지금 상황과 관련된 메모만 최대 3개** 넣습니다. 예: 크리퍼가 근처에 있으면 크리퍼 메모, 배고프면 음식 메모(회복량은 게임 데이터에서).

## 로그
터미널은 가볍게 유지합니다: 긴 줄은 200자에서 자르고(`LOG_MAX_CHARS`), 같은 메시지는 "N번 반복"으로 묶고, 300줄마다 화면을 지웁니다(`CLEAR_EVERY`, 0이면 안 지움). 잘리지 않은 전체 기록은 `data/bot.log`에 남습니다.

## 헛돌기 방지
스킬 작성이 2번 연속(각 3회 시도) 실패하면 `WRITE_COOLDOWN_STEPS`(6)턴 동안 스킬 작성을 막고 기존 스킬만 쓰게 합니다.

## 성공 판정
스킬이 에러 없이 끝나도 **인벤토리·위치(3칸 이상)·허기·주변 적대몹 수**가 하나도 안 바뀌면 "효과 없음"(실패)으로 칩니다. 새 스킬도 실제 효과가 있어야 저장됩니다.

## 두뇌 저장 / 정리
- **자동 저장**: 마일스톤 달성 때(`ms-<id>`, 영구 보관)와 `SNAPSHOT_EVERY_MIN`(기본 60분)마다(`auto`, 최근 10개만 유지) `brains/`에 `data/` 전체를 복사합니다.
- **정리**: 반성 4번마다(`CONSOLIDATE_EVERY`) 또는 배운 스킬이 `MAX_SKILLS`(25)를 넘으면, 먼저 저장한 뒤 한 번도 성공 못 한 스킬·5연속 실패 스킬·점수 낮은 스킬을 `data/skills/archive/`로 옮깁니다 (삭제 아님). 기본 스킬은 건드리지 않습니다.
```bash
npm run brain                     # 저장된 두뇌 목록
npm run brain -- save 이름         # 지금 상태 수동 저장 (영구 보관)
npm run brain -- restore 두뇌이름   # 봇을 끈 상태에서 복원 (직전 상태는 자동 백업)
```

## 무료 모드 (API 키 없이)
```bash
# 1) Ollama 설치: https://ollama.com  → 터미널에서 모델 받기
ollama pull qwen2.5:7b
ollama pull qwen2.5-coder:7b
# 2) 실행 (Node 20.6+)
cd minecraft-ai && npm install && npm run start:free
```
설정은 `.env.free`에 있습니다. GPU(VRAM 8GB 이상)가 있으면 쾌적하고, CPU만 쓰면 판단이 느립니다. 모델이 작아서 코드 작성 실패가 잦을 수 있으니, 성능이 부족하면 `SMART_MODEL=qwen2.5-coder:14b`처럼 키우거나 smart만 Claude로 바꾸세요.

## 비용 / 유료 모드
- 기본: fast=`claude-haiku-5-5`, smart=`claude-sonnet-5-5`. 24시간 기준 대략 하루 $12~15 (추정).
- `DAILY_BUDGET_USD`를 넘으면 봇이 자동으로 쉽니다 (다음 날 초기화).
- 무료: `FAST_PROVIDER=ollama` (+ 필요하면 `SMART_PROVIDER=ollama`). 로컬 모델은 코드 작성 품질이 낮을 수 있어, fast만 로컬로 두는 하이브리드를 추천합니다.

## 안전 주의
모델이 쓴 코드를 `node:vm`에서 실행합니다. 위험 식별자(`process`, `require`, `eval` 등)를 막고 `api` 객체만 노출하지만, **vm은 완전한 보안 경계가 아닙니다.** 전용 PC/컨테이너에서 돌리고, 봇 전용 서버를 쓰세요.

## 구조
```
src/index.js      접속·재접속
src/agent.js      관찰→판단→실행 루프, 스킬 실행/작성/수정, 반성
src/goals.js      현재 목표(고정 경로 → 스스로 정한 목표)와 자동 계획 텍스트
src/knowledge.js  게임 데이터 기반 레시피·도구·계획
src/util.js       공용 헬퍼 (sleep, 밤 판정 등)
src/actions.js    스킬 코드가 쓰는 api (gather/craft/smelt/attack/placeAt/digAt/equip/block/nearbyMobs/...)
src/sandbox.js    생성 코드 실행(금지어 검사 + 타임아웃)
src/skills.js     스킬 라이브러리 (data/skills)
src/curriculum.js 단계별 목표
src/llm.js        Claude / Ollama 어댑터 + 예산 가드
src/overlay.js    방송 오버레이 서버 (overlay/index.html)
```

## 아직 검증 안 된 부분
단위 테스트(`npm test`)는 통과하지만, 실제 마인크래프트 서버와의 연동(채집·제작·화로·전투)은 이 개발 환경에서 직접 돌려보지 못했습니다. 첫 실행에서 `api.*` 쪽 버그가 나올 수 있고, 에러는 로그와 오버레이에 표시됩니다.
