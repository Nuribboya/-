# 원청 후보 탐색 (자동제어 판넬 제조사용)

안성에서 자동제어 판넬(배전반·MCC·계장반)을 만드는 회사가 **새 원청을 찾되,
기존 원청(KC그룹)과 업종이 겹치지 않는 곳만** 골라내기 위한 도구입니다.

## 어떻게 찾는가

판넬 제조사의 원청은 결국 *판넬을 사서 현장에 넣는 쪽*입니다. 그래서 나라장터에서
**자동제어·계장·수배전 공사를 낙찰받은 업체**를 원청 후보로 잡습니다.
(발주기관은 직발주 가능성이 있어 별도 구분으로 같이 보여줍니다.)

```
나라장터 낙찰정보 ─┐
                   ├─→ 업체별 집계 ─→ DART 업종코드·주소 보강 ─→ 업종 겹침 판정 ─→ 점수/순위
발주기관(수요기관) ─┘                                              (KC그룹 제외)
```

### 업종 겹침 판정 4단계

| 판정 | 근거 | 기본 동작 |
|---|---|---|
| `계열사 의심` | 상호가 `케이씨`/`KC` 로 시작하거나 계열사 목록에 있음 | 제외 |
| `동일 업종` | DART 업종코드가 반도체·디스플레이 계열이거나, 상호/수주 공고명에 `반도체·클린룸·웨이퍼` 등 | 제외 |
| `인접 업종` | `전자재료·특수가스·2차전지·태양광` 등 전후방 연관 | 통과 (`--strict` 시 제외) |
| `무관` | 겹치는 신호 없음 | 통과 |

겹치는 후보는 감점이 아니라 **아예 목록에서 뺍니다**. 감점으로 섞으면 "안 겹치는 곳"이라는
조건이 순위에 묻히기 때문입니다. 뺀 이유는 `--include-excluded` 로 CSV에서 확인할 수 있습니다.

### 점수 (100점)

| 축 | 배점 | 내용 |
|---|---|---|
| 업종 적합도 | 40 | 판넬 물량이 꾸준한 업종인가 (수처리·발전·EPC·물류자동화 등 15개 업종, 가중치 차등) |
| 근접성 | 25 | 안성 기준 직선거리. 150km 넘으면 0점 |
| 수주 활동 | 25 | 최근 낙찰 건수·금액 (로그 스케일 — 대형 1건이 순위를 독식하지 않게) |
| 정보 확실성 | 10 | 사업자번호·업종코드·주소가 확보됐는가 |

## 실행

```bash
# 1) 키 없이 동작 확인 (가상 데이터)
python -m prime_contractor.cli screen --offline

# 2) 현재 적용 중인 제외 업종 / 타깃 업종 확인
python -m prime_contractor.cli show-config

# 3) 실제 조회
export G2B_SERVICE_KEY='공공데이터포털 인증키'
export DART_API_KEY='opendart 인증키'      # 선택 (업종코드 보강용)
python -m prime_contractor.cli screen --days 180 --out 원청후보.csv --include-excluded
```

주요 옵션

| 옵션 | 설명 |
|---|---|
| `--days N` | 최근 N일 낙찰 조회 (기본 180) |
| `--strict` | 인접 업종까지 제외 |
| `--min-awards N` | 낙찰 N건 미만 업체 제외 (일회성 업체 정리) |
| `--max-distance KM` | 근접 점수 0이 되는 거리 (기본 150km) |
| `--no-demand-orgs` | 발주기관은 빼고 시공사만 |
| `--config x.json` | 설정 교체 (`config.sample.json` 참고) |

## API 키 발급

| 키 | 발급처 | 필수 |
|---|---|---|
| `G2B_SERVICE_KEY` | [공공데이터포털](https://www.data.go.kr/data/15129397/openapi.do) → 「조달청_나라장터 낙찰정보서비스」 활용신청 | 필수 |
| `DART_API_KEY` | [opendart.fss.or.kr](https://opendart.fss.or.kr) 인증키 신청 | 선택 |

두 키 모두 무료이고 신청 즉시(또는 1~2시간 내) 발급됩니다.
조달청 키는 Encoding/Decoding 어느 쪽을 넣어도 됩니다 (퍼센트 인코딩을 자동으로 풀어 씁니다).

## 설정 바꾸기

`config.sample.json` 을 복사해서 쓰면 됩니다. 특히 이 두 가지는 실제 사정에 맞게 조정하세요.

- **`incumbent`** — 기존 원청 정의. 이 블록은 **통째로 교체**됩니다(빠뜨린 항목은 빈 값이 됨).
  KC그룹 계열사 상호나 업종코드를 더 정확히 아신다면 여기에 채워 넣는 편이 판정이 정확해집니다.
  실제 업종코드는 `python -m prime_contractor.cli dart-lookup 케이씨텍 케이씨이앤씨` 로 확인할 수 있습니다.
- **`sectors`** — 타깃 업종과 가중치. 이미 강한 업종은 가중치를 낮추고, 뚫고 싶은 쪽을 올리세요.

## 알아두실 점

- **나라장터는 공공 발주만 담습니다.** 민간 공장 증설 물량은 여기 안 잡힙니다.
  다만 공공 공사를 따내는 설비/전기 업체는 민간 일도 같이 하므로, 원청 후보 명단으로는 유효합니다.
- **DART는 공시대상 법인만** 있습니다. 비상장 중소업체는 업종코드가 안 붙고, 그 경우
  상호와 수주 공고명 키워드만으로 겹침을 판정합니다(= 판정 신뢰도가 낮음). CSV의 `업종코드`
  열이 비어 있으면 직접 확인이 필요한 건입니다.
- **거리는 시군구 대표좌표 기준 직선거리**입니다. 순위용 근사값이라 실제 주행거리와 다릅니다.
- 조달청 API는 `https` 가 아니라 `http` 이며 30 TPS 제한이 있습니다. 오퍼레이션 경로가
  개정될 때가 있어, 후보 경로를 순서대로 찔러보고 되는 것을 골라 쓰도록(probe) 되어 있습니다.
  전부 실패하면 어떤 경로에서 무슨 에러가 났는지 그대로 보여줍니다.
- `--offline` 데이터는 **가상 업체**입니다. 영업 리스트로 쓰지 마세요.
