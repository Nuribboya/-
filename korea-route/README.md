# Korea Route Planner (여행 동선 플래너)

가고 싶은 장소들을 넣으면 **가장 빠른 방문 순서**와 구간별 이동시간을 계산해 주는 정적 웹사이트.
외국인 관광객(영어)을 메인 타깃으로, 한국어도 지원한다.

## 기능

- 장소 검색(Photon, 실패 시 Nominatim) 또는 지도 클릭으로 추가
- 최적 방문 순서 계산 (`optimizer.js`)
  - 13곳 이하: Held-Karp 동적계획법으로 정확한 최적해
  - 그 이상: 최근접 이웃 + 2-opt 근사
- 이동 수단: 대중교통(거리 기반 추정) / 도보·자동차(OSRM 실제 도로 경로, 실패 시 추정)
- 왕복, "목록 마지막 장소에서 끝내기"(숙소/역) 옵션
- **📍 지금 위치에서 다시 짜기**: 방문 완료(✓)한 곳을 빼고 현재 위치 기준으로 재계산
- 구간별 카카오맵 / 구글맵 길찾기 링크
- 공유 링크(URL에 장소 목록 저장), 브라우저에 자동 저장
- 예시: 부산 당일치기, 부산 → 경주 → 통영 (도시 간 이동)

## 실행

빌드 없이 정적 파일만으로 동작한다.

```bash
cd korea-route
python3 -m http.server 8000   # http://localhost:8000
```

GitHub Pages, Cloudflare Pages 같은 무료 정적 호스팅에 이 폴더를 그대로 올리면 된다.

## 테스트

```bash
node --test korea-route/optimizer.test.js
```

## 한계와 다음 단계

- 대중교통 시간은 직선거리 기반 추정치다. 실제 시간표/환승 반영은 카카오모빌리티나 ODsay 같은
  대중교통 API(키 필요)를 붙여야 한다.
- 공개 데모 서버(OSRM, Photon, Nominatim, OSM 타일)를 쓰고 있어서, 트래픽이 늘면
  자체 서버나 유료/키 기반 API로 바꿔야 한다. (Nominatim은 초당 1회 제한)
- 영업시간, 식사 시간 같은 시간 제약은 아직 반영하지 않는다.
