# 토플 단어장

브라우저에서 `index.html`을 열면 하루 50개씩 새로운 TOEFL 단어를 보여줍니다
(날짜 기준으로 자동 순환되며, 서버 없이 정적 파일만으로 동작합니다).

- 단어마다 품사, 한국어 뜻, 동의어, 반의어가 함께 표시됩니다.
- 상단의 `◀ 이전 날` / `다음 날 ▶` 버튼으로 다른 날짜 목록을 미리 보거나 복습할 수 있습니다.
- `🖨 인쇄하기` 버튼을 누르면 체크박스와 버튼을 제외한 표만 인쇄됩니다.
- 암기 체크는 브라우저 로컬 저장소에 날짜별로 저장됩니다.
- 단어를 추가/수정하려면 `words.js`에 같은 형식으로 객체를 추가하면 됩니다.
